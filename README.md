# bm-device-integrity

Capacitor plugin for Google Play Integrity and Apple App Attest verification on Android and iOS.

## Install

To use npm

```bash
npm install bm-device-integrity
````

To use yarn

```bash
yarn add bm-device-integrity
```

Sync native files

```bash
npx cap sync
```
